### Computational biology · microbiome · multimodal ML · research agents

I work at the intersection of microbial ecology, neuroimaging and machine learning. My research asks how microbial communities and brain networks relate to health and disease, and how we can build models that remain useful when clinical data are incomplete.

I also build the software and agent infrastructure around that work: reproducible bioinformatics pipelines, multimodal benchmarks, and tool-using research assistants with evidence-grounded outputs.

**Currently:** preparing two companion manuscripts on availability-aware multimodal learning for incomplete clinical cohorts.

---

## Research

- Microbiome–neuroimaging integration in Parkinson's disease and cognitive decline
- Longitudinal and cross-sectional metagenomics (16S, ITS, shotgun, KEGG)
- Availability-aware / missing-modality learning for clinical multimodal data
- Reproducible evaluation: leak-free protocols, permutation controls, calibration, conformal prediction
- LLM agents for research: tool use, retrieval, verification and failure-mode evaluation

## Agent & LLM systems

I have built and evaluated tool-using research agents, including:

- function/tool calling with explicit confirmation gates for heavy actions
- evidence-grounded literature retrieval (PubMed/EuropePMC/OpenAlex/Semantic Scholar) with citation checks
- multi-provider LLM failover (Gemini/Groq/OpenRouter) and offline fail-closed mode
- headless evaluation: recommendation quality, grounding audits, data-quality injection tests and reproducibility capsules
- worker/local-runner infrastructure for user-owned compute
